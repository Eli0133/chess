# Python 象棋

以 Python 3.10 以上及 Pygame 重寫原本的 C++ / SFML 遊戲，原始檔案保留。

## 安裝與執行（Windows）

在此資料夾開啟終端機，執行：

```powershell
py -m pip install -r requirements.txt
py main.py
```

這台電腦也可直接雙擊 `start_python.bat`：啟動檔會優先使用使用者目錄下的 Miniconda，並載入已下載到 `.python-deps` 的 Pygame。搬到其他電腦時，建議依上方指令安裝套件。

若電腦使用 `python` 指令，將上述 `py` 改成 `python`。請保留同目錄的字型、圖片和 MP3；程式會從自身所在位置尋找素材，不受終端機目前位置影響。沒有音效裝置或個別音檔時仍可遊玩。

## 操作與功能

- 點擊標題畫面，選擇單人或雙人模式；紅方先走。
- 點選己方棋子，再點綠點或綠圈處移動／吃子；點另一顆己方棋子可重新選取。
- 單人模式由玩家執紅、電腦執黑。電腦沿用原版策略：優先隨機吃子，否則隨機選擇合法走法。
- 包含拐馬腳、塞象眼、炮架、過河、九宮、自陷將軍及將帥照面檢查。
- 吃掉將帥或讓對手無合法走法即可獲勝；無棋可走也判負。
- 提供棋子語音、移動／錯誤／將軍／勝利音效，以及重新開始和退出按鈕。
- 視窗預設 1280×720，可調整大小並保持棋盤比例。

與原版相同，未實作重複局面、長將及自然限著等和棋／裁判規則。

## 檔案

- `pieces.py`：棋子類別與各自的走法。
- `game.py`：棋盤、合法移動、將軍、勝負和簡易電腦對手。
- `main.py`：Pygame 畫面、輸入和音效。

規則測試：`py -m unittest discover -s tests -v`。
